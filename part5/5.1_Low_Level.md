 # Low-Level & Hardware Limits
 To compensate for that, we can use `Fixed-Point / Scaled Integers`. For example, instead of storing `5.25A` using double, we can store them using milivolts `mV` and miliamps `mA` using int, thus reducing size in memory.
 
 
 The lack of FPU, makes division very expensive. 
 Instead, we can use `bit shifting` to make the calculation cheaper.

 Another way of reducing the memory usage is to use constants when possible.
